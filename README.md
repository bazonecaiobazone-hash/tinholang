# tinholang

## o que é?
um pacote para arm64 por enquanto para administração de sistemas 
tinholang é uma linguagem de programação feita em rust que ainda esta em desenbolvimento

## criador
quem criou foi o usuario dono do repo bazonecaiobazone-hash

## codigo
ele não é apenas para arm pois o codigo fonte tem todo codigo para o cargo

## como compilar
para compilar use o comando

```bash
mv tinholang project
cd project
cargo build
cargo clean
```
